# Консигнация подрядчика CAT

Модель лежит в `consignment/`: `build_data.py` → `cons_data.json` → `make_xlsx.py` → книга →
пересчёт → `verify.py`. Методика и итоги — `consignment/README.md`, лист «Методика» книги.

## Порядок работы

1. **Источники.** План и история ТОРО — `data/<БЕ>_<год>.json` этого репозитория. Остатки,
   закупка и ЕК МТР — папка `Остатки-закупки-аналоги` репозитория `CAT` (ветка `rawdata`;
   в ней лежит media/rawdata на десятки ГБ — клонировать со sparse-checkout без `/media/` и
   `/rawdata/`). Замены номеров Cat — `data/stock.js` ветки `crm` репозитория `CAT`.
   Берётся самый свежий файл по маске `ЕКМТР*.xlsx`, `Остатки*.xlsx`, `Закупка*.XLSX`;
   дата «просрочено» — из имени файла закупки (`_ДД_ММ_ГГГГ`).
2. **Сборка данных:** `python consignment/build_data.py --src <папка> --stock-js <stock.js>`.
   Скрипт печатает по площадке число позиций, план, вне плана, остатки подрядчиков, поставки и
   исключённое — сверь с прошлым запуском, резкие скачки означают смену формата выгрузки.
3. **Книга:** `python consignment/make_xlsx.py` (`--limit 80` — быстрая проверочная сборка).
4. **Пересчёт:** openpyxl пишет формулы без значений. Для чтения значений — LibreOffice
   (`apt-get install libreoffice-calc`, иначе soffice зависает на xlsx) или скрипт `recalc.py`
   навыка xlsx. Около 300 тыс. формул, пересчёт ~15 с.
5. **Проверка:** `python consignment/verify.py <пересчитанная книга>` — должно быть 0
   расхождений на всех позициях. Любая правка формул в `make_xlsx.py` — зеркальная правка в
   `verify.py`, иначе проверка теряет смысл.
6. **Итоги** — лист «Сводка» (по площадкам, поле/цех, CAPEX/OPEX, помесячный ввод) и
   «Вне плана — анализ». Сценарии — меняй ячейки листа «Параметры» копии книги и пересчитывай.

## Определения, которые легко сломать

- **Площадка без перемещений.** Остатки: Красноярск — заводы `1100` и `7101`, Алдан — `1300` и
  `7103`. Закупка: `7101` / `7103`. ПБ КБЕ `7106` — справочно (через неё идёт ~311 млн заказов
  Красноярска). Задано в `SITES` (`stock_plants`, `plants`, `other_plants`).
- **Склады подрядчиков** — категория склада `5` в MM-M03 (ММФИ, REMAN Сервис, Сумитек,
  Восточная Техника…): не учитываются. Склад `7000` «Консигнация» и категория запаса АТЗ — тоже.
- **Колонки MM-M03** (данные, не подписи шапки — шапка смещена): 2 БЕ, 3 код завода, 4 завод,
  8 категория запаса, 9 материал, 11 номер производителя, 15 изготовитель, 16 категория склада,
  18 склад, 19 количество.
- **Закупка:** колонка 16 материал (или 14), 23 документ закупки, 30 статус, 32 «ещё поставить»,
  33 «в пути», 36 дата поставки по заказу. Действующий заказ — есть документ и статус
  «Действующий»/«Верифицирован»/пусто; прочее — «неподтверждённые» (по умолчанию выкл.).
- **Вне плана** — виды работ вне ТО и КР (`wclass`). Вероятность P = 1 − e^(−λ); минимум у
  использованных позиций ≈31% (один заказ за 32 месяца).
- **CAPEX/OPEX** — поле заказа `orr` («Причина инвестиций»), функция `capex_of`.
- **Исключения** (агрегаты, шины, GET, масла) — регулярки `EXCL` по наименованию.
- **Min/Max** — уровни позиции запаса (с учётом в пути). Стоимость, лимит и приоритет —
  от **запаса на площадке** (Max − средний спрос за срок пополнения). Не путать: при сроке
  90 дней разница ~200 млн.
- **План — детерминированно** по окну W месяцев, **не** Пуассоном: плановые КР крупными
  партиями иначе раздувают Min в разы.

## Грабли

- `CRITBINOM` с большим n в LibreOffice считает минутами — квантиль Пуассона в книге сделан
  через `SUMPRODUCT(POISSON(...))` при μ<20 и Корниша–Фишера при μ≥20.
- Не использовать `XLOOKUP`/`FILTER`/динамические массивы — LibreOffice их не считает.
- История 2024 по Красноярску неполная по объёму — поправка через «Коэффициент к истории».
- Цены — плановые ТОРО; при появлении прайса подрядчика подставлять в `price` в `build_data.py`.

## Добавить площадку или технику

Новый ключ в `SITES` (регулярка ЕО по «Технич. месту», заводы остатков и закупки), `model_of`
для подписи модели, при необходимости — столбец параметров на листе «Параметры» и лист
площадки в `make_xlsx.py` (цикл по `("1100", "Красноярск", "B"), ("1300", "Алдан", "C")`).
