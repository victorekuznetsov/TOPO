# TOPO — аналитика ТОиР горного оборудования

Интерактивный отчёт по выгрузкам **SAP BW PM-M06** (планирование и исполнение воздействий на производство).

## GitHub Pages

1. Репозиторий → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **`main`** / folder: **`/` (root)**
4. Сайт: `https://victorekuznetsov.github.io/TOPO/`

Файлы сайта:

- `index.html` — дашборд
- `dashboard_data.json` — агрегаты
- `.nojekyll` — отключает Jekyll

## Ветки

| Ветка | Содержание |
|---|---|
| `main` | Публичный HTML-отчёт |
| `rawdata` | Исходные Excel и split-zip SAP PM |

## Что внутри отчёта

- Заказы ТОРО, парк ЕО, группы МВЗ
- План/факт стоимости МТР, факт УСО и услуг
- Разрез площадка × год (Вернинское/Сухой Лог, Алдан, Магадан)
- Топ единиц оборудования и компонентов
- Методика КТГ / MTBF / MTTR (для следующей выгрузки с наработкой и остановами)

Включены все 21 выгрузка: **1100 Красноярск/Еруда**, 1200, 1300, 1400 и годы **2022–2027** (2023 нет у 1100/1200 — файла не было в rawdata).


## Интерактив

Открой `index.html` (данные вшиты, сервер не нужен).

Фильтры слева независимы и сочетаются:

- площадка, год, период (месяц базиса заказа)
- способ: хозспособ / УСО / комбинированный
- группа МВЗ, вид работы ТОРО
- показатель на графиках (план/факт МТР, УСО, услуги, заказы)

Вкладки:

- Сводка — динамика, площадки, способ, парк
- Материалы — компонент заказа
- Подрядчики УСО — рабочее место операции заказа
- Единицы оборудования

Клик по виду работ или парку ЕО добавляет фильтр (проваливание).
