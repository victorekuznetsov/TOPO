# Внешняя консигнация подрядчика CAT — модель 2027

Расчёт консигнационного склада подрядчика на двух площадках: **Красноярск (1100)** —
самосвалы 793D и ДВС 3516; **Алдан (1300)** — 773E, 777G, экскаваторы 395, ДВС C27/C32.
Один подрядчик на площадку, классическая консигнация (оплата при выдаче), только
оригинальные запчасти Caterpillar — без агрегатов, шин, GET, масел и смазок.

## Excel-версия без Python — `excel/Консигнация_CAT_Excel_PQ.xlsx`

Книга для обычного Excel: данные собирает **Power Query** прямо из выгрузок SAP, расчёт —
формулы (вычисляемые столбцы таблицы «Позиции»). Python не нужен.

1. Положить в одну папку: `M06_1100_<год>.xlsx`, `M06_1300_<год>.xlsx` (PM-06, год плана и три
   года до него), `Остатки*.xlsx` (MM-M03), `Закупка*.xlsx`, `ЕКМТР*.xlsx`, `Замены*.xlsx`.
2. Лист «Параметры»: папка, год плана, дата выгрузки закупки.
3. Один раз: Данные → Получить данные → Параметры запроса → Текущая книга → Конфиденциальность →
   «Игнорировать уровни конфиденциальности» (иначе ошибка Formula.Firewall — путь к папке берётся из книги).
4. Данные → Обновить все. Запрос «Позиции» перезаливает синие столбцы, формулы растягиваются сами.

Техника, заводы площадок и правила исключения — таблицы на листе «Настройки», их можно дополнять.
Код всех запросов — лист «Код Power Query» и `excel/Section1.m`.

| файл | что это |
|---|---|
| `excel/Консигнация_CAT_Excel_PQ.xlsx` | книга: запросы Power Query + формулы, предзаполнена данными на 11.09.2026 |
| `excel/section_template.m` | исходник запросов (M); `Section1.m` — готовый текст с итоговыми столбцами |
| `excel/make_pq.py` | пересборка книги после правки формул или запросов (встраивает запросы в xlsx) |
| `excel/verify_pq.py` | независимая проверка формул пересчитанной книги |

Формулы проверены: книга без запросов, пересчитанная LibreOffice, совпадает с Python-моделью на всех
3 633 позициях, сводка — 578 млн руб, как в версии 4. **Сами запросы Power Query здесь не исполнялись**
(в Linux нет движка M): проверен только их синтаксис официальным парсером. Первое обновление на
реальных выгрузках — в Excel.

## Как пересобрать

```bash
pip install openpyxl
# источники: репозиторий CAT, ветка rawdata — папка «Остатки-закупки-аналоги»;
# замены номеров Cat — data/stock.js ветки crm (или main) того же репозитория
python consignment/build_data.py --src "<CAT>/Остатки-закупки-аналоги" --stock-js "<CAT>/data/stock.js"
python consignment/make_xlsx.py
# пересчёт формул, чтобы прочитать значения скриптом (Excel пересчитает сам при открытии):
soffice --headless --convert-to xlsx --outdir /tmp/out consignment/Консигнация_CAT_2027.xlsx
python consignment/verify.py /tmp/out/Консигнация_CAT_2027.xlsx
```

Для LibreOffice нужен модуль Calc (`apt-get install libreoffice-calc`): без него `soffice`
молча не открывает xlsx и зависает до таймаута.

## Источники

* **План 2027** — предварительные заказы ТОРО, `data/1100_2027.json`, `data/1300_2027.json`:
  количество и стоимость МТР план, дата потребности, вид работ, причина инвестиций.
* **История вне плана** — факт 2024 – авг 2026 (`data/<БЕ>_2024…2026.json`) по видам работ
  вне ТО и КР: текущий ремонт, замена, монтаж/демонтаж, восстановление, прочие, «не присвоено».
* **Остатки** — MM-M03: только заводы площадки (Красноярск 1100 и 7101, Алдан 1300 и 7103),
  без складов подрядчиков (категория склада 5), действующей консигнации (склад 7000) и АТЗ.
* **Закупка АО «Развитие»** — только заводы площадки (Красноярск 7101, Алдан 7103).
  Перевалочная база КБЕ (7106) и другие заводы — справочно: попадут на площадку только перемещением.
* **ЕК МТР** — изготовитель и каталожный номер; **замены Cat** — `rep` из `stock.js` каталога CAT.

## Методика (кратко)

1. **Позиция** = код ЕК МТР на площадке; поле и цех в одной строке. Цех — заказы на ДВС и виды
   работ КР/среднего ремонта/восстановления. CAPEX — «OPEX УПА (CAPEX Рудных БЕ)»,
   «Капитализируемые ремонты», «Компоненты»; остальное — OPEX.
2. **Плановый спрос — по графику** (как MRP): Min_план = максимум плана за любые W подряд
   месяцев, W = срок пополнения в месяцах; Max_план = Min_план + план за период пересмотра.
3. **Спрос вне плана — вероятностно**: λ заказов в год по истории, P(использования в 2027) =
   1 − e^(−λ); в расчёт при P ≥ порога. Min/Max_вне = квантиль Пуассона числа заказов за
   L (L+R) × шт на заказ. Уровень сервиса относится к этой части.
4. **Min = Min_план + Min_вне; Max = max(Max_план + Max_вне; Min+1; макс. разовый отбор).**
5. **Сначала вырабатываем своё**: остаток + поставки по заказам в месяц прихода (просроченное —
   в начальный остаток, параметр задержки). Позиция входит в консигнацию в первом месяце, когда
   нарастающая потребность превышает (своё предложение − Min).
6. **Стоимость — физический запас на площадке**: макс. = Max − средний спрос за срок пополнения
   (он в пути у подрядчика), не меньше разового отбора; средний = страховой + (Max − Min)/2.
   Цена — плановая ТОРО 2027, для позиций только вне плана — средняя фактическая.
7. **Лимит**: позиции по убыванию «заказов в год на 1 млн руб запаса», пока хватает лимита.
