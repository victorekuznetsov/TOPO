# БДО — база данных оборудования из заказов ТОРО (PM-06)

Справочник техмест (ТМ) и единиц оборудования (ЕО), собранный из всех заказов ТОРО выгрузок PM-06
2022–2027 (ветка `rawdata`, 23 файла, 422 774 заказа). У заказа в PM-06 есть «Техническое место»
(код + имя) и «ЕО» (номер + имя), поэтому справочник содержит объекты, на которые были заказы;
промежуточные уровни ТМ без заказов известны только кодом.

Пересборка: `pm06_meta/bdo/build_all.sh <рабочая_папка>` (файлы качаются и сканируются по одному) →
`python3 pm06_meta/bdo/build_bdo.py <рабочая_папка> pm06_meta/bdo`.

## Структура (учебник «56_ТОиР_Ведение БДО и НСИ ТОиР»)

Оргструктура: завод планирования ТОРО → группы планирования (100 Механика, 200 Энергетика, 300 Метрология,
400 ЗиС, 500 Пожарная охрана, 600 АГиТО, 700 Эксплуатация…); завод расположения — где объект физически стоит.

Технические места — недвижимая иерархия («где»), уровни:

| Уровень | Смысл | Пример кода |
|---|---|---|
| 1 | ГОК / БЕ | `11` Красноярск, `05` Магадан, `06` Сухой Лог, `03` Вернинское, `04` Алдан |
| 2 | производство: ЗИФ, рудник, карьер, АТЦ, энергослужба | `11-RUD`, `05-KAR`, `06-ATC`, `11-ZIF` |
| 3 | цех / карьер / участок | `11-RUD-VOST`, `05-KAR-UOGR` |
| 4 | участок / линия / автоколонна | `11-RUD-VOST-UGVS`, `06-ATC-EKSK-OOBR` |
| 5 | технологическая позиция — машина | `11-RUD-VOST-UGVS-W304` «WK-35 №07» |
| 6+ | группирующие ТМ, узлы | `…-TA08-KI09-KI01` |

Глубина зависит от БЕ: машина WK — на 4-м уровне в Магадане (`05-KAR-UOGR-W201`), на 5-м в Красноярске,
на 6-м в Сухом Логу (`06-ATC-EKSK-OOBR-EXCV-EX04`). Родитель ТМ — код без последнего сегмента.

Единица оборудования — «что»: монтируется на ТМ, несёт тех. характеристики (марка, изготовитель, дата ввода),
связана с основным средством. На ТМ машины кроме самой машины стоят ЕО-узлы: ковш, рукоять, асинхронные ЭД,
редукторы, бортовой компьютер. ЕО переносится между ТМ (перемонтаж); при переводе в другой филиал меняется
код ТМ (памятка «изменение идентификатора ТМ»).

## Файлы

- `tm.json` — узлы ТМ (с предками): `код → [имя, уровень, родитель, первый год, последний год, заказов, ЕО]`.
- `eo.json` — ЕО: `номер → [имя, {год: ТМ}, марка, изготовитель, дата ввода, заказов]`.
- `wk.json` — ветка экскаваторов WK: машина (ТМ) → цепочка предков, ЕО на ТМ, заказы на ЕО-узлы.

## Что показали данные

- 12 684 ТМ с заказами (13 919 узлов с предками), 20 790 ЕО; у 3 611 ТМ больше одной ЕО.
- 53 740 заказов без ТМ и ЕО — позиции и суммарные заказы (APRO, ASR1, ARP1, ATU1…), не объектные.
- 1 187 заказов на ЕО без ТМ (демонтирована); 373 ЕО сменили ТМ за 2022–2027 (ЭД, насосы, ДВС, КПП, ковши),
  между БЕ — ни одной (при переводе меняется и номер ЕО: WK-20 №1220 — `03-RUD-…-EX04` → `06-ATC-…-EX04`).
- **Экскаваторы WK: 29 ТМ-машин; 119 заказов 2022–2027 стоят на ТМ машины, но на ЕО-узел** (ковш 56 заказов на
  314 млн ₽, рукоять 7 — 71 млн ₽, ЭД 47 — 16 млн ₽, редукторы, бортовой компьютер). План МТР+УСО 415 млн ₽
  (2027 — 189 млн ₽), факт 208,5 млн ₽. Отчёт WK отбирал заказы по имени ЕО и этих заказов не видел.
  Обратных случаев (ЕО WK не на ТМ WK) нет.
- Ковши переставляются между машинами: K1839.01.00 `100000146414` — W303 (2025) → W302 (2026).
